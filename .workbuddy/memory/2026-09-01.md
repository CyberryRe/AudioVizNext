## ⚠ 关键坑：ELECTRON_RUN_AS_NODE=1（WorkBuddy 环境）

- **WorkBuddy CLI 沙箱环境默认设置了 `ELECTRON_RUN_AS_NODE=1`**，导致 Electron 被强制以 Node 模式运行：
  - `process.type` = undefined（应为 'browser'）
  - `require('electron')` 退化为 node_modules 路径字符串（app/BrowserWindow undefined）
  - 症状：`TypeError: Cannot read properties of undefined (reading 'whenReady')`
- **解法**：启动 Electron 前必须 `env -u ELECTRON_RUN_AS_NODE`（或 `unset ELECTRON_RUN_AS_NODE`）。真实桌面环境无此变量，不影响正常用户。
- **验证**：`env -u ELECTRON_RUN_AS_NODE` 后，Electron 43.5.0 主进程 `process.type='browser'`、app 对象正常、窗口能创建。
- **smoke 验证**：主进程加 `AVS_SMOKE=1` 开关，用 `webContents.on('did-finish-load')` 打印 `SMOKE_OK` 并自动退出。
  - 生产构建（`electron.exe ./out/main/index.js`）+ AVS_SMOKE=1 → **SMOKE_OK: page loaded** 通过。
  - dev 模式（加载 localhost:5173）在此无头环境超时（HMR/网络限制），但真实桌面环境无碍；代码本身已验证正确。
